Zadanie 6 - Halyna

1) Rodzaje okienek

W JavaScript są trzy rodzaje okienek dialogowych:
- okienko alert – wyświetla okienko dialogowe z informacją i przyciskiem OK,
- okienko prompt – generuje okno, w którym użytkownik może wpisać wartość, zwracaną następnie do programu,
- okienko confirm – służy do tego, aby użytkownik coś potwierdził (stąd nazwa confirm).

2) Konwersji liczb

Wczytanie zmiennej z użyciem prompt wykonywane jest jako ciąg znaków, dlatego konieczna jest konwersja z ciągu znaków na wartości liczbowe, aby wykonywać obliczenia:
- parseFloat(zmienna) – konwersja zmiennej do typu float (liczba zmiennoprzecinkowa),
- parseInt(zmienna) – konwersja zmiennej do typu int (liczba całkowita),
- toString(zmienna) – konwersja zmiennej do typu łańcuchowego.

3) Przy nadawaniu nazw zmiennym należy przestrzegać pewnych zasad (trzy zasady):

Zasada 1. Nazwa zmiennej musi się zaczynać od litery, znaku $ lub _, może zawierać tylko litery (bez polskich znaków), cyfry oraz $ i _.
Poprawne nazwy zmiennych: zmienna1, $wynik, _rozmiar, wynik1, Rekord, $_gracz
Błędne nazwy zmiennych: 1zmienna, wynik gry, wysokosc&szerokosc, wynik.rekord, &gracz, wysokość, imie+nazwisko

Zasada 2. Wielkość liter ma znaczenie.
Rekord i rekord to dwie różne zmienne! Jest to bardzo częsta przyczyna błędów w kodzie początkujących programistów.

Zasada 3. Należy nie używać słów kluczowych JavaScript jako nazw zmiennych.

4) Omów typy zmiennych w Javascript

W JavaScript nie ma możliwości definiowania różnych typów zmiennych tak jak w C++, typy zmiennych są definiowane w trakcie ich przypisywania. Podstawowe typy to:
- Number – typ liczbowy (liczby całkowite i zmiennoprzecinkowe),
- String – typ tekstowy,
- Boolean – typ logiczny,
- Null – pusta zawartość,
- Undefined – typ niezidentyfikowany,
- Object – obiekt.
